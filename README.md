A compact chess engine in 4 KB of Python: alpha-beta search with quiescence, transposition table, null-move pruning, LMR, killer moves, and piece-square evaluation — plays the make.fun gauntlet via the environment protocol.

## Run it

```sh
python3 -P -s main.py
```

Requires `MAKEFUN_ENV_URL` to point at the game server (set by the harness).
